# 墨斗·Inkline 设计规范

> 适用范围：插件所有 HTML 界面（工具栏、抽屉、数据图表、图标库、切图规格、自定义词库、Toast）  
> 与画布侧输出（标注、图表、规范导出页）。  
> 版本：v0.5.21 ｜ 所有数值均取自代码，新增界面必须遵循本规范。
> 单位说明：本规范所有尺寸一律记作 **pt**（Sketch 单位），界面代码里的数值与本规范一一对应。

---

## 1. 设计令牌（CSS 变量）

所有界面 `:root` 必须引用同一套令牌，**禁止硬编码色值**。

| 令牌                      | 值                      | 用途              |
| ----------------------- | ---------------------- | --------------- |
| `--bg`                  | `#FAF9F6`              | 窗口底 / 工具栏底（暖白）  |
| `--bg-hover` / `--bg-2` | `#F1EEE6`              | 悬停底、分段控件底、浅底块   |
| `--bg-press`            | `#E7E3D8`              | 按下态             |
| `--line`                | `#E5E2DA`              | 常规边框、分割线        |
| `--line-soft`           | `#F0EDE6`              | 更浅的边框（次级分隔）     |
| `--line-2`              | `#D8D4C8`              | 强边框（坐标轴等）       |
| `--ink`                 | `#2B2B2B`              | 主文字             |
| `--ink-2`               | `#666666`              | 次级文字、说明文字、单位    |
| `--ink-3`               | `#999999`              | 弱文字、占位、清空钮      |
| `--ink-4`               | `#C9C4B8`              | 禁用、极弱图标         |
| `--accent`              | `#3868E6`              | 品牌蓝（强调、选中、主按钮）  |
| `--accent-h`            | `#2B55C4`              | 品牌蓝悬停           |
| `--accent-t`            | `rgba(56,104,230,.10)` | 品牌蓝 10% 底（选中背景） |
| `--seal`                | `#C0392B`              | 危险 / 删除（悬停变红）   |

| 圆角       | 值      | 用途                |
| -------- | ------ | ----------------- |
| `--r-sm` | `6pt`  | 输入框、chip、次级按钮     |
| `--r-md` | `8pt`  | 工具栏按键、主按钮、卡片、logo |
| `--r-lg` | `12pt` | 卡片容器、面板块          |

**动效**：`--ease: 0.12s ease`（所有 hover / 背景 / 边框过渡统一用它）

## 2. 字体

字体栈（全局，不允许换字体）：

```
-apple-system, "PingFang SC", "Helvetica Neue", sans-serif
```

字号阶梯（只允许使用下列档位）：

| 字号   | 字重        | 用途                              |
| ---- | --------- | ------------------------------- |
| 10pt | 400       | 工具栏按键文字（`.tbtn .lbl`）、图例文字      |
| 11pt | 400       | 抽屉说明（`.drawer-title`）、单位标签      |
| 12pt | 400       | 输入框、`chip`、次级按钮、数据表、数据值         |
| 13pt | 400 / 600 | 分段控件（`.seg`）、主按钮（600）           |
| 14pt | 400 / 600 | 区块标题（`.cap`）、提示文字、窗口标题行         |
| 15pt | 600       | 环形图中心合计数值（图表内，随直径缩放）            |

- 次级/说明文字统一 `14pt #666666`（区块标题、落点提示、预览提示）。
- 图表内 SVG 文字：刻度 10、类别 11、数值 10、图例 10（小尺寸时按比例缩小）。
- 图表插入画布后分为两个子组：**数据图**（几何 + 类别/数值标签）与**图例**（色块 + 文字），可整组拖动/隐藏/删除，互不牵动。

## 3. 组件规格

### 3.1 工具栏（`.bar`）

| 项           | 规格                                                              |
| ----------- | --------------------------------------------------------------- |
| 条高          | 56pt                                                            |
| 内边距         | `0 10pt`，子项间距 `gap: 2pt`                                        |
| 按键 `.tbtn`  | **44 × 46pt**，圆角 `--r-md`，纵向排列，`gap: 4pt`                       |
| 按键图标 `.ic`  | **22 × 22pt**（SVG `viewBox 0 0 24 24`，`currentColor`）           |
| 按键文字 `.lbl` | 10pt，最短 2 字                                                     |
| Logo        | 34 × 34pt，圆角 `--r-md`，右外边距 8pt（主拖拽把手，`data-app-region="drag"`）  |
| 分割线 `.sep`  | 1 × 24pt，左右外边距 5pt                                              |
| 关闭键         | 44 × 46pt，图标 22pt，位于最右（前面必须有 `.sep`）                            |
| 窗口宽         | **内容自适应**（页面实测最后一个按键右缘 + 10pt 右 padding 回报 `barWidth`），当前 886pt |
| 状态          | 悬停 `--bg-hover`；选中/激活 `--accent-t` + `--accent` 文字              |

> 新增按钮：44 宽 + 图标 22 + ≤2 字文字，无需手动改窗口宽度（自动校正）。

### 3.2 按钮家族

| 组件          | 规格                                                                                              | 用途                 |
| ----------- | ----------------------------------------------------------------------------------------------- | ------------------ |
| 次按钮 `.btn`  | 12pt，`padding 5pt 10pt`，圆角 6，白底 + `1pt --line`，悬停 `--bg-hover`                                  | 普通操作（添加一行、随机示例）    |
| 主按钮 `#go`   | 13pt / 600，`padding 9pt 20pt`，圆角 8，`--accent` 底白字，悬停 `--accent-h`                               | 每个窗口最多 1 个（插入到画板）  |
| 标签块 `.chip` | 12pt，`padding 5pt 11pt`，圆角 6，白底 + 边框；**选中**：`--accent-t` 底 + `--accent` 边框 + `--accent` 文字      | 可多选的开关/样式项         |
| 分段控件 `.seg` | 容器 `padding 3pt`、圆角 10、底 `--bg-2`；选项 `padding 7pt 20pt`、13pt、圆角 8；**选中**：白底 + `--accent` 文字 600 | 互斥视图切换（柱状图/折线图/饼图） |
| 删除钮 `.rm`   | 20 × 20pt 圆，`1pt --line`，悬停变 `--seal`；禁用 `opacity .35`                                          | 删除数据行              |
| 卡片 `.card`  | 100 × 60pt，圆角 8，`gap 3pt`，白底 + 边框，选中为品牌蓝                                                        | 切图规格选择             |

### 3.3 输入家族

| 组件           | 规格                                                                |
| ------------ | ----------------------------------------------------------------- |
| 文本输入         | 12pt，`padding 5pt 8pt`（高约 30pt），圆角 6，`1pt --line`，聚焦边框 `--accent` |
| 数字输入 `.snum` | 同文本输入，**右对齐**，隐藏上下箭头（spinner），宽度：数据值 72pt / 尺寸 60pt               |
| 清空钮 `×`      | 内嵌输入框内部右侧 7pt，12pt 字号，`--ink-3`，悬停 `--seal`；**无边框无圆圈**            |
| 滑杆           | `accent-color: var(--accent)`，右侧数值 11pt + 单位                      |
| 单位标签 `.unit` | 11pt `--ink-2`（pt / ×）                                            |

> **规则：所有输入数值的地方都必须带内嵌 `×` 清空钮**（数值输入框统一 `.snum` + `.numwrap`）。

### 3.4 数据表行

`序号 14pt --ink-3` ｜ `类别输入 flex:1` ｜ `数值输入 72pt` ｜ `删除钮 20pt`；行间距 `gap 6pt`，列表最大高 176pt 可滚。

### 3.5 窗口

| 窗口    | 尺寸                 | 最小尺寸      | 标题                    |
| ----- | ------------------ | --------- | --------------------- |
| 工具栏   | 886(自适应) × 56（+抽屉） | —         | `墨斗·Inkline`          |
| 数据图表  | 700 × 600          | 620 × 480 | `墨斗·Inkline · 数据图表`   |
| 图标库   | 420 × 680          | 360 × 480 | `墨斗·Inkline 图标库`      |
| 自定义词库 | 420 × 520          | —         | `墨斗·Inkline · 自定义词库`  |
| Toast | 随文字，高 40           | —         | 独立透明窗口，距面板底 16pt，鼠标穿透 |

- 所有辅助窗口 `alwaysOnTop: floating`，工具栏额外 `setAlwaysOnTop(true,'floating',1) + moveTop()`。
- 抽屉：`padding 10pt 12pt`，白底，上边框 `1pt --line`，高度按内容实测回报。

## 4. 间距与布局

- 基准间距：**2 / 4 / 6 / 8 / 10 / 12 / 14pt**（不出现其它散值）。
- 窗口内边距：工具栏 `0 10`，数据图表 `14pt 16pt 0`，抽屉 `10 12`。
- 区块（`.grp`）下间距 12pt；区块标题（`.cap`）下间距 7pt。
- 左右两栏布局：左列固定 356pt，列间距 14pt。

---

## 5. 图标

- 工具栏图标 **22pt**；图标库网格图标 **28pt**；Logo 34pt。
- 统一 SVG `<symbol>` + `<use href="#i-xxx">`，颜色用 `currentColor`，跟随文字色。
- 图标网格：自适应列宽，单格最小 64pt。
- 白底 Logo 落在浅色底上必须加描边：1pt 内描边（`rgba(31,31,31,.06)`）+ 2pt 投影（`rgba(31,31,31,.10)`）。
- 图标必须 `pointer-events: none`（拖动把手 / 点击命中父元素）。

## 6. 图表规范（数据图表）

**尺寸语义**：输入的是**图形本体**尺寸，不含图例。

| 项         | 规格                                                            |
| --------- | ------------------------------------------------------------- |
| 柱状图 / 折线图 | 宽 × 高 = 本体（默认 480 × 320pt，可手输 100–2000 / 80–1500）             |
| 饼图        | **直径**（默认 100pt，24–1000）；环形内径输入的是**环宽**（0 = 实心，内圈半径 = R − 环宽） |
| 描边        | 固定**白色**，手输 0–8pt，0 = 无描边（不提供颜色选项）                            |
| 图例        | 右侧独立列，**距本体 40pt**；列宽按最长条目文字自适应，行高 24pt，色块 10×10 圆角 2，文字 10pt；插入后与数据图**各自独立编组** |
| 画布留白      | 四周最小 **8pt**，左右内边距按刻度数字 / 数值标签 / 类别文字**实测宽**收紧（v0.5.21，不再写死魔数） |
| 坐标        | 4 段刻度；网格线 `#EFECE4`，轴线 `#D8D4C8`，刻度字 10pt `#9A958A`           |
| 类别 / 数值标签 | 11pt / 10pt `#666666`；折线数值在点上方 11pt                           |
| 折线        | 线宽 2.5pt 圆头，数据点圆 r = 3.5pt                                    |

**图表调色板（8 色多彩）**：

| 序号 | 1         | 2         | 3         | 4         | 5         | 6         | 7         | 8         |
| -- | --------- | --------- | --------- | --------- | --------- | --------- | --------- | --------- |
| 色值 | `#3868E6` | `#12B5A5` | `#F2A03D` | `#8B5CF6` | `#E2506B` | `#2FA84F` | `#0EA5E9` | `#F0641E` |

单色模式统一品牌蓝 `#3868E6`。预览与插入必须同源（`chartgen.js`），所见即所得。

## 8. 交互状态（统一）

| 状态 | 表现                                                       |
| -- | -------------------------------------------------------- |
| 悬停 | 背景 `--bg-hover`；强调类用 `--accent-t` + `--accent` 文字        |
| 按下 | `--bg-press` / `rgba(56,104,230,.18)`                    |
| 选中 | `--accent-t` 底 + `--accent` 边框 + `--accent` 文字（chip/seg） |
| 禁用 | `opacity: .35`，`cursor: default`                         |
| 聚焦 | 边框变 `--accent`                                           |

过渡时长一律 `0.12s ease`。

## 9. 开发约定（硬性）

1. **颜色/圆角/动效只用令牌**，禁止硬编码；新界面必须复制 `:root` 令牌块。
2. **新增工具栏按钮**：44×46、图标 22、文字 ≤2 字、前面按需加 `.sep`；窗口宽度会自动校正（页面 `reportBarWidth` → 插件 `CUR_W`）。
3. **所有数值输入**用 `.snum` + `.numwrap` + 内嵌 `.clr`（× 清空钮）。
4. **同类可选多项用 `chip`，互斥切换用 `seg`，确认动作用主按钮**。
5. 所有提示走 `panel-ref.js` 的 `toast()`；窗口标题统一 `墨斗·Inkline · XX` 并同步 `follow.js` 的 `OUR_TITLES`。
6. 窗口引用一律模块级变量 + `isLive()` 存活检测，禁止 `getWebview(identifier)` 反查。
7. 图表相关改动必须同步 `chartgen.js`（预览与插入共用），并跑 node 断言。
8. 版本号三件套同步：`package.json` / `src/manifest.json`（bundleVersion+1）/ `src/version.js`。
