# Inkline · 墨斗 🖌

> Sketch 标注 / 交付 / 素材插件 —— 在设计稿上「弹墨线」。

Kitchen 与 Sketch Measure 两款经典插件已不再支持新版 Sketch，原有标注、切图、尺寸查看等能力无法继续使用。**Inkline・墨斗** 复刻并优化了这两款插件的核心交付能力，为 Sketch 用户提供一个稳定可用的替代方案。

- 全部功能**离线可用**，不依赖任何服务端
- 数据只存在本地（`NSUserDefaults`），不上传、不联网同步
- 兼容 Sketch 2026 及以上

---

## 安装

1. 从 [Releases](https://github.com/cxf825/inkline/releases) 下载最新的 `inkline-vX.Y.Z.sketchplugin.zip` 并解压
2. 双击 `inkline.sketchplugin`，或 `Plugins → Manage Plugins → Install Plugin from Disk…` 选择它
   （装过旧版 Kitchen3 / Inkline 请先在插件管理里卸载）
3. 重启 Sketch，菜单栏出现 `Plugins → Inkline · 墨斗`

打开插件：菜单 `Plugins → Inkline · 墨斗 → 打开 / 关闭工具栏`，或快捷键 **⌃⌘B**。

## 功能一览

### 1. 悬浮工具栏面板

Sketch Measure 式的横向悬浮条，常驻画布上方。按住「墨」Logo 拖动位置，跟随 Sketch 窗口显示/隐藏，始终置顶不被画布遮挡。

点击「文本」「图片」「色板」「分割」「设置」会向下展开抽屉；抽屉高度按内容自动伸缩，再点一次收起。

### 2. 尺寸与间距标注

选中图层后一键标注，自动生成标注图层（统一 `INK-` 前缀，便于识别与清除）。

| 功能 | 说明 | 快捷键 |
|---|---|---|
| 标注宽度 | 标注图层宽度 | ⌃⇧2 |
| 标注高度 | 标注图层高度 | ⌃⇧6 |
| 标注间距 | 单选标注到画板四边距离；多选标注两两间距 | ⌃⇧3 |
| 标注属性 | 标注字号 / 行高 / 颜色等文本属性 | ⌃⇧4 |
| 清除全部标注 | 清空当前页所有标注图层 | ⌃⇧5 |

标注统一使用 11px 字号与红/蓝/紫三色体系，输出风格保持稳定。

### 3. 注释便签

选中图层后添加带编号的注释便签（⌃⌥N），适合在交付稿上写实现说明，同样可通过「清除标注」一并清理。

### 4. 色板管理

- **文档取色**：自动扫描当前页所有图层的填充、描边、文字颜色，按使用频次排序
- **我的色板**：收藏常用颜色，持久化保存，跨文档可用
- 点击色块即可复制色值，方便贴到代码或规范文档里

### 5. 切图导出

选中图层批量导出 **PNG @1x / @2x / @3x**，矢量图层额外导出 **SVG**。

- 多选且同属一个编组/画板时，自动按该编组名建立子文件夹
- 单选整个编组时，子文件夹取编组自身名称

### 6. 图形分割

把选中的画板/图形按 **行 × 列 − 间距 − 页边距** 切成等分网格矩形，做「一键切九宫格 / 列表占位」这类活很快。参数不合理（间距过大导致无剩余空间）会给出明确提示。

### 7. 离线规范导出（HTML）

一键把当前页导出为**单文件离线 HTML 规范文档**（⌃⇧E）：

- 画板预览图 + 标注叠加层，可在页面上切换标注显示
- 自动收集**颜色规范**与**字体规范**（字号 / 字体 / 行高）
- 纯静态文件，双击即看，可直接丢给开发或归档，无需任何环境

### 8. 图标库（⌃⌥I）

独立的图标窗口，两种模式：

- **本地模式**：内置 Iconify 全量图标搜索，网格墙浏览，点击即插入
- **官网模式**：内嵌 iconfont.cn（登录态原生保留），支持官网中文搜索、收藏、我的项目

细节体验：

- 收藏改成图标右上角小圆钮，不遮挡图标
- 插入后自动选中图标并把镜头定位过去，不会「找不到插到哪了」
- 插入落点优先级：**选中的画板 → 镜头所在画板 → 当前聚焦画板 → 第一块画板**

### 9. Mock 数据填充

给设计稿快速灌入逼近真实的数据，检查布局在真实内容下的表现。

- **Mock 文本**（⌃⌥T）：根据图层名**智能匹配类型**——名字里带「手机 / 邮箱 / 价 / 地址 / 日期 / 姓名」等关键词时，自动填对应格式的假数据；否则填段落文案
- **Mock 图片**（⌃⌥M）：随机图片填充，可指定本地图片目录循环使用
- **自定义词库**：独立窗口编辑，一行一条，持久化保存

数据全部本地生成，离线可用。

### 10. 一键解锁

解锁当前页**全部**锁定图层（⌃⇧L），包含嵌套在编组内的图层，解锁完成后提示解锁数量。

## 版本号规则

`X.Y.Z`：小更新滚动最后一位（0.1.1 → 0.1.2）；大功能升第二位（0.2.0）；正式发布升第一位（1.0.0）。

> 版本号唯一来源：`src/version.js`（帮助弹窗 / 面板设置抽屉读它）+ `package.json` + `src/manifest.json` 的 `bundleVersion`，三处同步。

## 开发

```bash
cd inkline
npm install        # 首次
NODE_OPTIONS=--openssl-legacy-provider npm run build   # 构建 → inkline.sketchplugin
NODE_OPTIONS=--openssl-legacy-provider npm run watch   # 开发时增量构建
```

构建后双击 `inkline.sketchplugin` 覆盖安装，重启 Sketch 生效。
